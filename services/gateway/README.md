# Сервис Gateway

Gateway преобразует внешний HTTP API в gRPC-вызовы внутренних сервисов.
Обычные маршруты регистрируются из сгенерированных grpc-gateway handlers;
кастомные HTTP handlers нужны только для BFF и оркестрации.

## Конфигурация

- `GATEWAY_HTTP_ADDRESS` — адрес публичного HTTP API, по умолчанию `:3000`;
- `SWAGGER_HTTP_ADDRESS` — адрес отладочного API и Swagger, по умолчанию `:3001`;
- `CATALOG_GRPC_ADDRESS` — обязательный адрес Catalog;
- `JWT_SECRET`, `JWT_ISSUER`, `JWT_AUDIENCE` — обязательные параметры JWT.

## Локальная проверка

Из этого каталога тесты работают без `go.work`:

```bash
GOWORK=off go test ./...
```

Для ручного запуска нужно предварительно поднять Catalog и передать
обязательные переменные окружения. `/healthz` проверяет сам процесс,
`/readyz` — доступность обязательных зависимостей.
