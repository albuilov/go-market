# Безопасность и границы доверия

Gateway является единственной точкой проверки внешнего JWT. Публичность RPC
задаётся protobuf-аннотацией `auth.v1.authorization`; отсутствие аннотации
означает приватный метод по умолчанию.

Перед внутренним вызовом Gateway удаляет `x-user-id` и `x-user-roles`, которые
мог прислать внешний клиент, затем добавляет значения из проверенного токена.
Сервисы могут читать эти поля через `internal/platform/identity` только если
соединение действительно пришло из доверенной внутренней сети.

Текущие gRPC-клиенты используют insecure credentials для локальной Docker-сети.
Для production этого недостаточно.
